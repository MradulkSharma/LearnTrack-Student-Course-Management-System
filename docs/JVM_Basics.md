# JVM Basics

## JDK
JDK means Java Development Kit. It is used to write and compile Java programs.

## JRE
JRE means Java Runtime Environment. It helps run Java programs.

## JVM
JVM means Java Virtual Machine. It runs the Java bytecode.

## Bytecode
Java code is compiled into bytecode before it is run.

## Write once, run anywhere
Java code can be written once and run on any machine that has a JVM installed. That is why Java is portable.

## Simple example
We write `.java` files, compile them with `javac`, and run them with `java`.
